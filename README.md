# ระบบจัดการแผนที่ติดตั้งอุปกรณ์ภายในอาคาร (Indoor Equipment Map)

เว็บแอปพลิเคชันจัดการแผนที่และตำแหน่งติดตั้งอุปกรณ์ภายในอาคาร (เช่น กล้องวงจรปิด CCTV, ถังดับเพลิง, เครื่องตรวจจับควัน) พัฒนาด้วย **React 19 + TypeScript + Vite + Tailwind CSS** ออกแบบสำหรับการใช้งานจริง ลื่นไหล รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Responsive & Touch Gestures) โดยเริ่มต้นแบบ Clean State ไม่มีข้อมูลเดโมติดมา

---

## 🌟 ฟังก์ชันหลักของระบบ

### 1. การจัดการแผนที่ผังอาคาร (Floor Plan Map)
- **รองรับหลายรูปแบบไฟล์:** รองรับภาพแผนที่นามสกุล PNG, JPG, JPEG และ SVG ขนาดสูงสุด 25 MB
- **ระบบนำทางแผนที่เต็มรูปแบบ:**
  - **Zoom In / Zoom Out:** ซูมเข้า-ออกได้ทั้งผ่านปุ่มบน Toolbar, ทางลัดคีย์บอร์ด (`+`, `-`), และล้อเมาส์ (Mouse Wheel) แบบจุดซูมอิงตำแหน่งเคอร์เซอร์
  - **Pan:** คลิกค้างแล้วลากแผนที่เพื่อเลื่อนดูมุมต่างๆ อย่างลื่นไหล
  - **Fit to Screen:** ปุ่มปรับขนาดแผนที่ให้พอดีกับกรอบหน้าจอและจัดกึ่งกลางอัตโนมัติ (ปุ่ม `🔲`)
  - **Reset 100%:** รีเซ็ตขนาดกลับสู่สเกล 1:1 กึ่งกลางหน้าจอ
- **พิกัดแบบ Normalized Coordinates (0.0 ถึง 1.0):** บันทึกตำแหน่งหมุดอุปกรณ์เป็นค่าสัมพัทธ์ตามสัดส่วนจริงของแผนที่ ทำให้ตำแหน่งหมุดไม่คลาดเคลื่อนไม่ว่าจะย่อ/ขยายหน้าจอ ซูม หรือเปลี่ยนขนาดแผนที่

### 2. การเพิ่มและจัดการจุดติดตั้งอุปกรณ์
- **โหมดเพิ่มจุดติดตั้ง:** คลิกปุ่ม "เพิ่มจุดติดตั้ง" จากนั้นคลิกตำแหน่งใดก็ได้บนแผนที่เพื่อวางหมุด (กด `Esc` เพื่อยกเลิก)
- **ประเภทอุปกรณ์และสีแยกชัดเจน:**
  - 📹 **กล้องวงจรปิด (CCTV):** สัญลักษณ์กล้อง สีน้ำเงินอินดิโก้ (`#2563eb`)
  - 🧯 **ถังดับเพลิง (Fire Extinguisher):** สัญลักษณ์ถังดับเพลิง สีแดง (`#dc2626`)
  - 🚨 **เครื่องตรวจจับควัน (Smoke Detector):** สีส้ม (`#ea580c`)
  - 📶 **เราเตอร์ / Access Point:** สีฟ้าคราม (`#0284c7`)
  - 🚪 **ทางออกฉุกเฉิน (Emergency Exit):** สีเขียว (`#16a34a`)
  - 🩹 **จุดปฐมพยาบาล (First Aid):** สีชมพูบานเย็น (`#be185d`)
- **การลากหมุดเพื่อเปลี่ยนตำแหน่ง (Drag & Reposition):**
  - สามารถคลิกลากหมุดไปยังตำแหน่งใหม่ได้ทันทีทั้งเมาส์และหน้าจอสัมผัส
  - มีระบบ **Boundary Clamping** ป้องกันไม่ให้ลากหมุดหลุดออกนอกขอบเขตของแผนที่อย่างเด็ดขาด

### 3. รายละเอียดและรูปภาพจริงของอุปกรณ์ (Equipment Details & Photos)
- คลิกหมุดบนแผนที่หรือเลือกจากรายการ เพื่อเปิดหน้ารายละเอียดด้านข้าง (Side Panel Drawer):
  - **ชื่ออุปกรณ์** (เช่น กล้องวงจรปิด ทางเข้าหลัก L1)
  - **ประเภทอุปกรณ์** (พร้อม Badge สีประจำประเภท)
  - **รหัสอุปกรณ์** (เช่น CCTV-01, FE-02)
  - **ตำแหน่งหรือโซน** (เช่น โถงต้อนรับ, บันไดหนีไฟ A)
  - **ชั้น / อาคาร** (เช่น ชั้น 1 อาคารนวัตกรรม)
  - **วันที่ติดตั้ง**
  - **สถานะการใช้งาน:** ใช้งานปกติ (สีเขียว), ต้องตรวจสอบ (สีส้ม), ชำรุด (สีแดง)
  - **หมายเหตุ / รายละเอียดเพิ่มเติม**
- **คลังรูปภาพจริงของอุปกรณ์:**
  - รองรับการอัปโหลดรูปภาพจริงได้หลายรูป (Multi-photo upload)
  - มีระบบแสดงภาพตัวอย่าง (Preview) ก่อนบันทึก
  - หากไม่มีภาพ จะแสดงข้อความระบุ **"ยังไม่มีรูปภาพ"**
  - มีระบบ **Lightbox Viewer** ขยายภาพเต็มจอ พร้อมปุ่มเลื่อนดูภาพถัดไป/ก่อนหน้า สลับดูผ่าน Thumbnail และปิดด้วยปุ่ม Esc

### 4. การจัดการข้อมูลและการสำรองไฟล์ (Data Management)
- **ค้นหาและกรองข้อมูล:**
  - ช่องค้นหาด่วนตามชื่อ, รหัสอุปกรณ์, โซน, อาคาร หรือหมายเหตุ
  - ตัวกรองแยกตามประเภทอุปกรณ์
  - ตัวกรองแยกตามสถานะการใช้งาน
- **สัญลักษณ์ สถิติ และการเปิด/ปิดการแสดงผล (Legend & Visibility):**
  - แถบสรุปจำนวนอุปกรณ์แต่ละประเภทและแต่ละสถานะ
  - สัญลักษณ์ระบุประเภทและสี
  - ปุ่มรูปดวงตา (👁️) เปิด/ซ่อนหมุดแต่ละประเภทบนแผนที่ได้อย่างอิสระ
- **ระบบสำรองและถ่ายโอนข้อมูล (Export / Import JSON):**
  - ส่งออกข้อมูลเป็นไฟล์ JSON (รวมข้อมูลแผนที่, รายการอุปกรณ์, พิกัด และรูปภาพจริง)
  - นำเข้าไฟล์ JSON พร้อมระบบตรวจสอบความถูกต้องของโครงสร้างไฟล์ (Schema Validation)
- **การจัดเก็บอัตโนมัติ (IndexedDB Persistence):**
  - บันทึกข้อมูลลงใน IndexedDB ของเบราว์เซอร์อัตโนมัติทุกครั้งที่มีการเพิ่ม แก้ไข ย้าย หรือลบ
  - **รีเฟรชหน้าจอหรือปิดเบราว์เซอร์แล้วข้อมูลไม่สูญหาย** ทั้งภาพแผนที่และรูปภาพความละเอียดสูง

### 5. ประสบการณ์ใช้งานและดีไซน์ (UI/UX)
- อินเทอร์เฟซทันสมัย สะอาด อ่านง่าย คุมโทน Dark Slate สไตล์ Enterprise
- ภาษาไทยเป็นหลัก
- ระบบแจ้งเตือน Toast แจ้งสถานะบันทึกสำเร็จ ผิดพลาด หรือแจ้งเตือนความคืบหน้า
- ระบบป้องกันการลบข้อมูล (Confirmation Modal) ยืนยันก่อนลบจุดติดตั้งหรือล้างข้อมูล
- รองรับการใช้งานทั้ง เมาส์, คีย์บอร์ด, และ Gestures บนสมาร์ตโฟน/แท็บเล็ต (Pinch-to-zoom, Pan, Drag)
- มี Error Boundary ป้องกันหน้าขาวเมื่อเกิดข้อผิดพลาดที่ไม่คาดคิด

## 🚀 วิธีการติดตั้งและเริ่มต้นใช้งาน

### ข้อกำหนดเบื้องต้น
- **Node.js:** เวอร์ชัน 18 ขึ้นไป (แนะนำ v20 หรือ v24)
- **npm:** เวอร์ชัน 9 ขึ้นไป

### 1. เข้าสู่โฟลเดอร์โปรเจกต์
```bash
cd indoor-map-manager
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. รัน Development Server
```bash
npm run dev
```
เมื่อรันสำเร็จ ให้เปิดเบราว์เซอร์ไปที่ URL ที่แสดง (โดยปกติคือ `http://localhost:5173`)

### 4. รันชุดแบบทดสอบ (Automated Tests)
โปรเจกต์มีชุดแบบทดสอบครบถ้วน (24 แบบทดสอบผ่านทั้งหมด 100%):
```bash
# รันการทดสอบทั้งหมดครั้งเดียว
npm test

# หรือรันในโหมด Watch
npm run test:watch
```

### 5. Build สำหรับ Production
```bash
npm run build
```
ไฟล์ที่ถูกคอมไพล์และ Optimize เรียบร้อยแล้วจะถูกสร้างไว้ในโฟลเดอร์ `dist/`

### 6. ทดสอบพรีวิว Production Build
```bash
npm run preview
```

## 📖 คู่มือการใช้งานระบบ

1. **อัปโหลดแผนที่ผังอาคาร:**
   - เมื่อเปิดแอปครั้งแรก คลิกปุ่ม **"อัปโหลดแผนที่ผังอาคาร"**
   - เลือกไฟล์หรือลากไฟล์ภาพแผนที่ (PNG, JPG, SVG) มาวาง
   - ตรวจสอบภาพพรีวิวและขนาด จากนั้นคลิก **"ใช้แผนที่นี้"**
2. **การซูมและเลื่อนดูแผนที่:**
   - ใช้ล้อเมาส์หมุนขึ้นเพื่อซูมเข้า หมุนลงเพื่อซูมออก
   - หรือคลิกปุ่ม `+` / `-` บน Toolbar
   - คลิกปุ่ม `🔲` (Fit to Screen) เพื่อปรับให้แผนที่พอดีกับหน้าจอทันที
   - คลิกค้างบนพื้นที่ว่างของแผนที่แล้วลากเพื่อเลื่อนดู (Pan)
3. **การเพิ่มจุดติดตั้งอุปกรณ์:**
   - คลิกปุ่ม **"เพิ่มจุดติดตั้ง"** บน Header หรือ Toolbar
   - สังเกตแถบแจ้งเตือนด้านบน "โหมดเพิ่มจุดติดตั้ง" และเคอร์เซอร์จะเปลี่ยนเป็นรูปเป้าเล็ง
   - นำเคอร์เซอร์ไปคลิกตำแหน่งที่ต้องการติดตั้งบนแผนที่
   - กรอกข้อมูลอุปกรณ์:
     - เลือกประเภทอุปกรณ์ (เช่น กล้องวงจรปิด หรือ ถังดับเพลิง)
     - ระบุชื่ออุปกรณ์, รหัสอุปกรณ์, ตำแหน่ง/โซน
     - เลือกวันที่ติดตั้ง และสถานะการใช้งาน
     - แนบรูปภาพจริงของอุปกรณ์ (สามารถเลือกได้หลายภาพ)
   - คลิก **"บันทึกจุดติดตั้ง"** หมุดจะปรากฏบนแผนที่ทันที
4. **การย้ายตำแหน่งหมุด:**
   - นำเมาส์ไปคลิกค้างที่หมุดใดๆ บนแผนที่แล้วลากไปยังตำแหน่งใหม่
   - ระบบจะป้องกันไม่ให้ลากหมุดหลุดออกจากขอบเขตของแผนที่ และบันทึกพิกัดใหม่ลงใน IndexedDB ทันที
5. **การดูและแก้ไขรายละเอียด:**
   - คลิกที่หมุดอุปกรณ์ใดๆ บนแผนที่ หรือคลิกเลือกจากรายการในแถบด้านข้าง
   - หน้าต่าง Side Panel จะเลื่อนแสดงข้อมูลทั้งหมด
   - คลิกที่ภาพถ่ายอุปกรณ์เพื่อเปิดดูแบบ **Lightbox ขยายภาพเต็มจอ** สามารถกดลูกศรเลื่อนดูภาพถัดไปได้
   - คลิกปุ่ม **"แก้ไขข้อมูล"** เพื่อปรับปรุงข้อมูลหรือเพิ่ม/ลบภาพถ่าย
   - คลิกปุ่ม **"ลบจุดติดตั้งนี้"** เพื่อลบหมุดออก (จะมีหน้าต่างยืนยันก่อนลบเสมอ)
6. **การค้นหาและกรองข้อมูล:**
   - พิมพ์คำค้นหาในช่องค้นหาบนแถบด้านข้าง (ค้นหาได้ทั้งภาษาไทยและอังกฤษ)
   - เลือกกรองเฉพาะ "กล้องวงจรปิด" หรือ "ถังดับเพลิง"
   - เลือกกรองเฉพาะสถานะ "ใช้งานปกติ", "ต้องตรวจสอบ" หรือ "ชำรุด"
7. **การซ่อน/แสดงหมุดบนแผนที่:**
   - ไปที่แท็บ **"สถิติ/สัญลักษณ์"** ในแถบด้านข้าง
   - คลิกที่ไอคอนรูปดวงตา (👁️ / 👁️‍🗨️) ด้านหลังประเภทอุปกรณ์ที่ต้องการซ่อนหรือแสดง
8. **การสำรองข้อมูล (Export / Import):**
   - ไปที่แท็บ **"จัดการข้อมูล"** ในแถบด้านข้าง
   - คลิก **"ส่งออกข้อมูลเป็นไฟล์ JSON (Export)"** เพื่อดาวน์โหลดไฟล์สำรองทั้งหมดลงเครื่อง
   - เมื่อต้องการกู้คืนข้อมูลหรือย้ายเครื่อง ให้คลิก **"นำเข้าข้อมูลจากไฟล์ JSON (Import)"** แล้วเลือกไฟล์ JSON
